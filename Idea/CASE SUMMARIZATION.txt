Suppose there is a BPM system for a bank or any financial institution, the BPM system creates cases as per the client/customer requests and these cases are worked upon.
The cases are created in such a way that each case will have,

1. Specific Type - Will have business specific terminology
2. Specific Sub-Type - Will have business specific terminology
3. All the cases go through 5 stages, from start to end.
4. Comments added to it while it is being processed in each stage. The comments may have business abbreviations and terminologies.
5. Timestamps of how long the case was in each stage.
6. Might or might not have documents attached to it.

All the above details of cases would be stored in a CSV file.

I want to create an application that summarizes and explains all the cases in bulk, and individual cases as well depending upon the request or the application user.

Now, as mentioned in case details, a case can have business terminologies and abbreviations. To have the absolute and correct meaning of these said terminologies and abbreviations, the application must use RAG mechanism to fetch the details of business/company specific terminologies.

The application must be a Gen-AI or Agentic-AI application that,

1. Takes input from user (set of cases or individual case)
2. Reads all the case details from CSV, identifies the business/company terminologies or abbreviations used.
3. Visits the data store using RAG, where the abbreviations and business/company terminologies have been defined.
4. Gathers the case details fetched and data collected from RAG, summarizes the case or cases
5. Provides output summary to the user.
